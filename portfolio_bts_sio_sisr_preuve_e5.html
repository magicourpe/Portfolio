Guide de Déploiement GitHub Pages

Procédures pour rendre votre portfolio accessible en ligne

Étape 1 : Nommage du Dépôt GitHub

Créez un nouveau dépôt public nommé exactement : votre-pseudo.github.io

Étape 2 : Structure des Fichiers

Placez ce fichier code enregistré sous le nom exact de index.html à la racine du dépôt.

Étape 3 : Fichier .nojekyll (Optionnel mais conseillé)

Ajoutez un fichier vide nommé .nojekyll pour désactiver la compilation Jekyll par défaut sur GitHub.

Étape 4 : Activation de GitHub Pages

Rendez-vous dans Settings ➔ Pages ➔ Build and deployment, sélectionnez la branche main ou master et cliquez sur Save.
